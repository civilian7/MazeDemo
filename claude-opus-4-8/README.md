# MazeDemo3D — 1인칭 3D 미로 게임 (Opus 4.8)

이전 모델 **Opus 4.5**(`../claude-opus-4-5`)가 만든 VCL 2D 미로 데모와 **동일한 컨셉**을,
Opus 4.8 이 **FireMonkey 실제 3D · 1인칭 시점 게임**으로 재구성한 성능 비교용 데모입니다.

미로 생성(Recursive Backtracking)과 경로 탐색(BFS) 코어 로직은 그대로 계승하고,
3D 렌더링·자유 이동(FPS) 조작·게임 요소를 새로 구현했습니다.

## 빌드 / 실행

- 환경: **Delphi 13 (Studio 37.0) · FireMonkey · Win64**
- IDE: `MazeDemo3D.dproj` 열고 실행(F9)
- 커맨드라인:
  ```
  "C:\Program Files (x86)\Embarcadero\Studio\37.0\bin\dcc64.exe" MazeDemo3D.dpr
  ```
- 산출물: `MazeDemo3D.exe` (Win64)

## 조작

| 키 | 동작 |
|---|---|
| `W` / `↑` | 전진 |
| `S` / `↓` | 후진 |
| `A` / `D` | 좌/우 스트레이프 |
| `←` `→` (또는 `Q` `E`) | 시선 회전(3D) / 좌우 이동(2D) |
| `H` | 힌트(출구 방향 화살표 3초) |

> **2D 모드**에서는 시선 회전 없이 화살표/WASD로 상하좌우 절대 이동합니다. **마우스로 드래그**하면 캐릭터가 그 지점을 향해 미로를 따라 이동합니다(벽에서는 미끄러짐). 플레이어는 델파이 1.0 로고의 여신을 단순화한 캐릭터로 표시됩니다.

상단 바에서 가로/세로 크기를 정하고 **미로 생성**을 누르면 먼저 **2D 평면도**가 표시됩니다(입구 S·출구 E 표시). 평면도를 확인한 뒤 **게임 시작**을 누르면 선택한 모드로 진입합니다.

- **모드: 3D / 2D** 버튼 — 1인칭 3D ↔ 위에서 내려다보는 2D 플레이를 전환(게임 도중에도 가능).
- **해답 보기 / 숨기기** 버튼 — 입구→출구 최단 경로(BFS)를 표시. 2D에선 경로 라인, 3D에선 바닥 발광 트레일로 보여줍니다.

## 게임 요소

- **2D 평면도 미리보기**: 생성 직후 전체 미로를 위에서 내려다보는 평면도로 표시.
- **2D / 3D 플레이 모드 전환**: 1인칭 3D 또는 탑다운 2D로 진행(게임 중에도 즉시 전환).
- **해답(경로찾기) 표시**: BFS 최단 경로를 2D 라인 / 3D 바닥 트레일로 토글.
- **1인칭 3D**: `TViewport3D` + **벽돌 텍스처가 입혀진** 큐브 메쉬 벽 + 카메라.
- **제한 시야(안개)**: 카메라에 부착된 포인트 토치 라이트만으로 비추어 먼 곳은 어둠.
- **수집품/열쇠**: 코인(점수)과 열쇠 1개. **열쇠를 먹어야 출구가 열립니다**(포털이 녹색으로).
- **미니맵 HUD**: 우상단. 탐험한 칸만 드러나는 fog of war + 플레이어 방향 + 힌트 화살표.
- **자동 힌트**: 현재 칸에서 출구까지 BFS 로 다음 방향을 미니맵에 표시.
- **제한시간**: 기본 90초. 시간 초과 시 패배, 열쇠 획득 후 출구 도달 시 승리.

## 구조 (유닛별 단일 책임)

| 유닛 | 책임 |
|---|---|
| `Maze.Core.pas` | 미로 생성·BFS 경로 탐색(임의 칸→출구 포함). 순수 데이터, UI 무관 |
| `Maze.Player.pas` | 1인칭 이동·시선·벽 충돌(축 분리). 월드 좌표/시선각 제공 |
| `Maze.Scene.pas` | 코어 미로 → 3D 씬(바닥/천장/벽/수집품/출구/토치) 구성·갱신 |
| `Maze.Minimap.pas` | HUD 미니맵 렌더(fog of war, 플레이어/힌트) |
| `MainForm.pas` | 3D 뷰·게임 루프(~60fps)·입력·상태머신·HUD 총괄 |
